# India state map data

The state and union territory boundary paths in `india-state-paths.json` are a simplified, adapted subset of the `vardhan-maps` India boundaries, which are derived from OpenStreetMap. The source set includes best-effort boundary corrections for India's external depiction; it is not an official or survey-grade map.

The adapted map data is made available under the Open Database License (ODbL) v1.0.
